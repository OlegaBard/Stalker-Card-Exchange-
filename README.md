# ☢️ S.T.A.L.K.E.R. 2 — Discord обмінник карток

Повноцінний Discord-бот для колекціонування та обміну карток S.T.A.L.K.E.R. 2. Увесь геймплей — через **кнопки**, **меню вибору** та **embed-повідомлення** (без текстових команд для гравців).

## Можливості

| Розділ | Опис |
|--------|------|
| 📦 Моя колекція | Зібрані / відсутні / дублі, прогрес-бар, оновлення схрону |
| 🔁 Обмін дублів | Вибір «віддаю» → «хочу» → публікація на ринку |
| 🧾 Ринок | Канал `#card-trade-market` з кнопками Прийняти / Профіль / Скарга |
| 🔍 Пошук | Деталі будь-якої з 48 карток |
| 🏆 Суперпушка | Прогрес до 48/48 та SUPER WEAPON TOKEN |
| ❓ Правила | Embed з правилами Зони |

## Структура каналів Discord

```
📁 S.T.A.L.K.E.R. CARDS
  📢 card-news
  🔁 card-trade-market
  📦 card-collections
  🏆 card-completed
  ❓ card-rules
```

## Швидкий старт

### 1. Створити бота

1. [Discord Developer Portal](https://discord.com/developers/applications) → New Application → Bot
2. Увімкни **Privileged Gateway Intents**: Server Members (за потреби)
3. Запроси бота на сервер з правами: Send Messages, Embed Links, Use External Emojis, Read Message History

### 2. Налаштування

```bash
cp .env.example .env
# Заповни DISCORD_TOKEN та ID каналів
pip install -r requirements.txt
```

### 3. Запуск

```bash
python run.py
```

### 4. Опублікувати меню

У каналі `#card-collections` (або іншому) виконай від імені адміна:

```
/stalker_setup
```

Гравці натискають кнопки в закріпленому повідомленні — головне меню працює постійно (persistent views).

## Змінні середовища

| Змінна | Опис |
|--------|------|
| `DISCORD_TOKEN` | Токен бота |
| `GUILD_ID` | ID сервера (швидша синхронізація slash-команд) |
| `CHANNEL_CARD_TRADE_MARKET` | Ринок обміну |
| `CHANNEL_CARD_COLLECTIONS` | Дзеркало нових пропозицій (опційно) |
| `CHANNEL_CARD_COMPLETED` | Повні колекції / нагороди |
| `CHANNEL_CARD_RULES` | Правила |
| `ADMIN_ROLE_ID` | Роль модератора (опційно) |

## Адмін-команди

| Команда | Дія |
|---------|-----|
| `/stalker_setup` | Опублікувати головне меню |
| `/stalker_rules` | Опублікувати правила |
| `/stalker_grant` | Видати/забрати картки гравцю |

Гравці додають картки самі через **«Оновити схрон (+1)»** у колекції (чесна реєстрація з гри).
